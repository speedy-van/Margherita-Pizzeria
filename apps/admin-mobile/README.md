# Margherita Admin Mobile

Expo/React Native admin app for Margherita Pizza staff.

## Backend

The app uses the public production backend:

```text
https://www.margheritapizza.uk
```

Do not submit builds that point to local, LAN, tunnel, or preview URLs.

## App Store Notes

- The reviewer should use the staff demo account provided in App Store Connect.
- The app requires sign-in because it is an operations tool for restaurant staff.
- Push notifications are used for new order and booking alerts.
- App icon and brand assets are bundled in `assets/icons`.
